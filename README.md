### 🌟 What is Gen AI X App?

[Gen AI X App](https://genaixapp.com) is an **autonomous app-building agent** that turns natural language prompts into real, multi-file iOS and Android mobile apps in minutes—with zero boilerplate and no vendor lock-in.

You describe your product vision, and the agent designs the interface, models complex application state, configures native dependencies, and compiles the project into WebAssembly for live in-browser previewing, high-DPI screenshot exports, and instant physical device testing via QR codes.

### ⚡ Core Architecture & Engineering Highlights

- 🤖 **Autonomous App-Building Agent**: Multi-turn agent architecture that plans features, structures multi-file Dart 3 projects, and validates functionality.
- 📱 **Interactive In-Browser Simulator**: Test, touch, scroll, and interact with the compiled mobile app in real-time with realistic chassis, iOS dynamic island, and platform controls.
- 📲 **Instant QR Code On-Device Testing**: Scan a QR code to run the generated native mobile app directly on your physical iPhone or Android device via Snack SDK.
- 🔁 **Self-Healing Compiler Loop**: Google Cloud Run micro-compiler inspects compilation diagnostics and triggers targeted self-repair turns for zero-downtime builds.
- 🔄 **1-Click GitHub Synchronization**: Seamlessly sync your generated codebase directly to private or public GitHub repositories for complete code ownership.
- 💳 **Production Billing & Rollover Protection**: Stripe Billing integration supporting monthly subscription tiers and non-expiring one-time packs with 12-month rollover protection.
